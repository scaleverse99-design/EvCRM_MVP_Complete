YOUTUBE API .ENV SETUP
=======================

Add this ONE line to the bottom of your .env file
(location: C:\Users\balaj\Downloads\EvCRM_MVP_Complete\evcrm-mvp\.env)


-----------------------------------------------------------
YOUTUBE_API_KEY=AIzaSy...paste-your-key-here
-----------------------------------------------------------


RULES:
------
1. No quotes needed around the key.
2. NO SPACES around the = sign.
3. Must be on ONE line.

4. IMPORTANT — do NOT name it NEXT_PUBLIC_YOUTUBE_API_KEY
   Anything starting with NEXT_PUBLIC_ gets bundled into the
   browser JavaScript, where anyone viewing your site could
   read it and burn your quota. This key is server-side only.

5. Copy the key you just created (restricted to
   "YouTube Data API v3"), NOT the "Browser key (auto created
   by Firebase)" — that one is used client-side by Firebase.


WHERE TO GET THE KEY
--------------------
Google Cloud Console -> APIs & Services -> Credentials
-> find the key you created -> click the copy icon

If you closed the page before copying: you can always view an
existing key again from that same Credentials list (unlike the
Meta token, Google lets you re-view API keys).

NOT NEEDED FOR AUTOCOMPLETE
---------------------------
YouTube search autocomplete (what people type into the YouTube
search box) needs NO key at all - it uses the same public
endpoint your Google autocomplete already uses. Already verified
working. The key is only for view counts and comments.
